# Descomplica ADS — Java

Repositório acadêmico para organizar aulas, anotações, exercícios, atividades e projetos desenvolvidos durante a graduação em **Análise e Desenvolvimento de Sistemas (ADS) na Faculdade Descomplica**, com foco na linguagem **Java**.

## Objetivos

- Registrar minha evolução no aprendizado de Java.
- Organizar os conteúdos estudados por assunto.
- Praticar lógica de programação e orientação a objetos.
- Reunir exercícios, atividades acadêmicas e projetos.
- Manter um histórico de estudos utilizando Git e GitHub.

## Organização dos estudos

Cada pasta reúne códigos relacionados ao conteúdo correspondente. Sempre que possível, os arquivos terão nomes descritivos e comentários que ajudem a compreender a solução.

## Convenção sugerida para commits

- `docs:` documentação e anotações
- `feat:` novos exercícios ou funcionalidades
- `fix:` correções
- `refactor:` melhorias no código
- `test:` testes

Exemplo: `feat: adiciona exercício de estruturas condicionais`
